Посчитать сумму всех платежей для каждого клиента, включая клиентов без платежей.

SQL-решение
task_02.sql

    Client,

FROM A

Фильтрация по назначению платежа

Получить сумму платежей по клиентам, если текст назначения начинается с «договор». Связать таблицы клиентов, платежей и назначений.

SQL-решение
task_04.sql
SELECT
    Client,
    SUM(Payments)
FROM A
JOIN B ON A.ID = B.ID
JOIN E ON B.Pay_id = E.Pay_id
WHERE Purpose LIKE 'договор%'
GROUP BY A.ID, Client;

05

Заблокированные номера с активностью

Найти заблокированные номера с более чем тремя активностями «Должник лично». Подсчёт ведётся по телефону должника суммарно по всем его договорам.

SQL-решение
task_05.sql
SELECT
    P.NUMBER,
    P.DEBTOR_ID,
    STRING_AGG(DISTINCT A.ASSET_NUM::text, ', ') AS ASSET_NUM,
    P.ID,
    (SELECT COUNT(*)
     FROM PHONES P2
     WHERE P2.NUMBER = P.NUMBER) AS number_count,
    MAX(AC.CREATED) AS last_activity
FROM PHONES P
JOIN ACTIONS AC
    ON P.DEBTOR_ID = AC.DEBTOR_ID
    AND P.NUMBER = AC.PHONE_NUM
JOIN ASSET A ON A.ID = AC.ASSET_ID
WHERE P.BLOCK_FLG = 'Y'
    AND AC.WHOM_CONTACT = 'Должник лично'
GROUP BY P.NUMBER, P.DEBTOR_ID, P.ID
HAVING COUNT(*) > 3;

Если у номера несколько договоров, их номера выводятся через запятую. Количество повторений номера считается по всей таблице PHONES.

06

Уникальные контакты

Подсчитать в двух столбцах уникальные email-адреса и номера телефонов со статусом marketing_deny по всей таблице contacts.

SQL-решение
task_06.sql
SELECT
    COUNT(DISTINCT CASE
        WHEN contact_type = 'email' THEN contact
    END) AS uniq_mail,
    COUNT(DISTINCT CASE
        WHEN contact_type = 'номер телефона' THEN contact
    END) AS uniq_num
FROM contacts
WHERE status = 'marketing_deny';

07

Анализ изменения ОСЗ

Для каждого должника вычислить предыдущую задолженность, абсолютное и процентное изменение по датам из stock_prices.

SQL-решение · CTE + LAG
task_07.sql
WITH previous_debt AS (
    SELECT
        stock_id,
        price_date,
        price,
        LAG(price) OVER (
            PARTITION BY stock_id
            ORDER BY price_date
        ) AS previous_price
    FROM stock_prices
)
SELECT
    stock_id,
    price_date,
    price,
    previous_price,
    price - previous_price AS price_difference,
    ROUND(
        100.0 * (price - previous_price)
        / NULLIF(previous_price, 0),
        2
    ) AS percentage_change
FROM previous_debt
ORDER BY stock_id, price_date;
